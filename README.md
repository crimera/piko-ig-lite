Opinionated and lean [Piko](https://github.com/crimera/piko) patch bundle for Instagram.

# Patches
- AMOLED theme
- Disable swipe to camera
- Downloads
- Ghost mode
- Hide feed ads
- Hide reels and stories ads

# Compatibility
- 451.0.0.53.80 (385713073)
- 449.0.0.52.84 (385511871)
- 448.0.0.52.84 (385412061)
